Modell

Denktiefe

PC-Steuerung

Buddy sieht dabei deinen Bildschirm und benutzt Maus und Tastatur. Stoppen kannst du jederzeit mit deinem Tastenkürzel oder dem Stopp-Knopf im Island.

Mitteilungen

Status –

Schalte in Windows «Nicht stören» ein, dann poppt unten rechts nichts mehr auf und alles kommt nur noch im Island. Die Inhalte bleiben auf deinem PC.

Sprache

Spracherkennung –

Sprich über das Mikrofon im Island, dein Tastenkürzel oder mit «Hey Buddy». Das Zuhören auf «Hey Buddy» passiert nur auf deinem PC und braucht etwas Rechenleistung, deshalb ist es standardmässig aus.

Musik

Funktioniert mit Spotify, YouTube im Browser und allen Apps, die Windows als Wiedergabe meldet.

Kalender

Kalender Nicht verbunden

Google Kalender: Einstellungen → dein Kalender → «Privatadresse im iCal-Format». Outlook: Einstellungen → Kalender → Freigegebene Kalender → «Kalender veröffentlichen» → ICS-Link. Der Link wird verschlüsselt gespeichert.

Eigene Kurzbefehle

Ein Kurzbefehl schickt Buddy einen festen Auftrag, z. B. «Pausier die Musik» oder «Stell einen Timer auf 5 Minuten». Das klappt von überall, auch wenn das Island zu ist.

Allgemein

Im Spielmodus versteckt sich Buddy, sobald ein Spiel oder eine Vollbild-App läuft: keine Pop-ups, kein Ton, keine PC-Steuerung. Verpasste Mitteilungen zeigt er danach.

Datenschutz

Buddy läuft auf deinem PC und hat keine eigenen Server. Es gibt keine Werbung und keine Statistiken.

An Claude (Anthropic) geht nur, was du Buddy schreibst oder sagst, seine Antworten und, nur bei der PC-Steuerung, Bildschirmfotos. Das läuft über deinen eigenen API-Key.

Nur auf deinem PC bleiben: API-Key und Kalender-Link (verschlüsselt), Chatverlauf, Mitteilungen, Musik-Infos, Kalender-Termine und das Protokoll. Mitteilungen und Termine sieht Claude nur, wenn du danach fragst.

Sprache: «Hey Buddy» wird auf dem PC erkannt. Fürs Diktat nutzt Buddy die Spracherkennung von Windows; ist dort die Online-Erkennung an, verarbeitet Microsoft das Gesprochene.

Updates lädt Buddy von GitHub, sobald das Repo öffentlich ist.
